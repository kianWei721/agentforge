# AgentForge V0.2：Agent CRUD + Tool Registry + Function Calling

## 目标

V0.2 的核心不是继续增加模型供应商，而是建立 Agent 平台最关键的运行边界：

```text
Agent Definition
      |
      +---- model
      |
      +---- tools
              |
         Tool Registry
              |
       AgentScope Adapter
              |
          Toolkit
              |
       HarnessAgent ReAct
              |
        Function Calling
```

## 本阶段新增

### 1. Agent Definition / CRUD

新增 `agentforge-agent` 模块。

提供：

- `POST /api/v1/agents`
- `GET /api/v1/agents`
- `GET /api/v1/agents/{agentId}`
- `PUT /api/v1/agents/{agentId}`
- `DELETE /api/v1/agents/{agentId}`

V0.2 使用内存 Repository，重启会丢失动态创建的 Agent。数据库持久化放到后续阶段。

### 2. AgentForge Tool SPI

业务 Tool 不直接依赖 AgentScope：

```text
AgentTool
  |
  +-- name
  +-- description
  +-- JSON Schema
  +-- readOnly
  +-- concurrencySafe
  +-- execute(context, arguments)
```

AgentScope 依赖被封装在 `AgentScopeToolAdapter` 中。

这样未来可以切换 Runtime 框架，而不要求业务 Tool 重写。

### 3. Tool Registry

`DefaultToolRegistry` 负责：

- 工具注册
- 名称唯一性
- Agent 绑定工具校验
- 工具描述查询
- 运行时按 Agent toolNames 解析工具实例

接口：

`GET /api/v1/tools`

### 4. 第一个业务 Tool

`query_device_status`

当前执行链路：

```text
LLM
 |
 | tool call
 v
AgentScope Toolkit
 |
 v
AgentScopeToolAdapter
 |
 v
DeviceStatusTool
 |
 v
DeviceStatusQueryPort
 |
 v
DemoDeviceStatusQueryAdapter
```

注意：V0.2 默认 Adapter 是确定性的演示数据，不代表已经连接真实生产 IoT 平台。

后续只需替换 `DeviceStatusQueryPort` 的 Infrastructure Adapter，即可接入真实 HTTP/RPC/DB 查询。

### 5. Tool Call Trace

Agent SSE 不再只有文本，新增：

- `model_call_start`
- `model_call_end`
- `tool_call_start`
- `tool_call_end`
- `tool_result_start`
- `tool_result_delta`
- `tool_result_end`
- `message`
- `done`

因此前端后续可以直接绘制 Agent Execution Trace。

## Runtime Cache

`AgentRuntimeManager` 按 `agentId + AgentDefinition.version` 缓存 HarnessAgent。

Agent 配置更新后：

1. version + 1；
2. 原 Runtime 失效并关闭；
3. 下一次请求按新 Prompt / Model / Tools 重建 Runtime。

这样既保留 Session，又避免每次 HTTP 请求重建 Agent。

## 当前限制

- Agent Definition 仍是内存存储；
- Session 仍使用 `InMemoryAgentStateStore`；
- AgentScope Runtime 当前只支持 DashScope model provider；
- DeviceStatusQueryPort 目前是 Demo Adapter；
- 尚未持久化 Tool Trace。
