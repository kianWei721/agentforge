# V0.3 Persistence Infrastructure

## Scope

本阶段处理 MySQL Agent 持久化和 Redis 基础接入。Docker Compose 仅作为可选开发工具，不是运行依赖。

## External infrastructure mode

开发机无需安装 Docker。只需要准备一个可访问的 MySQL 和 Redis，并执行：

    .\scripts\configure-infra.ps1

连接信息会写入本地 .env.local。密码不会进入 Git。

MySQL 建议使用独立数据库 agentforge；不要把 Flyway 指向现有生产业务 schema。

Flyway 需要该数据库上的建表和版本变更权限。Redis 当前只做连接和健康探测。

## Persistence boundary

领域层只依赖 AgentDefinitionRepository；MySQL/JDBC 实现在 agentforge-infrastructure。

## WebFlux and JDBC

JDBC 是阻塞 I/O，所以 Agent CRUD、Health、Runtime 首次读取 Agent Definition 都在 boundedElastic 上执行，避免阻塞 Netty EventLoop。

## Verification

    .\scripts\mvn.ps1 clean test
    .\scripts\run-dashscope.ps1

然后检查 /api/v1/system/health，预期 mysql=UP、redis=UP。

创建 Agent 后重启 JVM，再按 id 查询；仍存在即证明 MySQL 持久化闭环。
