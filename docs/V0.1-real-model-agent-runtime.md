# AgentForge V0.1：真实模型 + AgentScope Runtime

## 本阶段目标

V0 已经验证 `HTTP -> ModelGateway -> Reactor -> SSE`。
V0.1 不引入数据库、RAG 或 Tool Calling，先把两个关键基础设施打通：

1. `ModelGateway -> Provider Router -> DashScope/Qwen` 真实模型流式调用；
2. `HTTP -> AgentRuntime -> AgentScope HarnessAgent -> AgentEvent -> SSE` Agent 运行时链路。

## 当前结构

```text
ChatController
    |
ModelGateway
    |
RoutingModelGateway
    |
+-------------+----------------+
|                              |
MockModelProvider      DashScopeModelProvider
                               |
                       DashScopeChatModel
                               |
                              Qwen
```

## AgentScope HarnessAgent POC

当前 Agent runtime 有意关闭文件系统、Shell、动态 Skill、SubAgent、Memory tools 和 workspace tools.json。

原因：本阶段只验证 `RuntimeContext(userId, sessionId)`、多轮会话状态隔离、AgentEvent 和 SSE。业务工具从 Week 2 开始通过 AgentForge Tool SPI 接入。

当前会话状态使用 `InMemoryAgentStateStore`：

- 同一进程内同一 `userId + sessionId` 可以连续对话；
- 重启进程后状态消失；
- 后续再切 Redis / durable state。

## 配置

Mock：

```powershell
$env:AGENTFORGE_MODEL_PROVIDER="mock"
$env:AGENTFORGE_AGENT_ENABLED="false"
mvn -pl agentforge-app -am spring-boot:run
```

DashScope + AgentScope：

```powershell
$env:DASHSCOPE_API_KEY="你的 Key"
$env:DASHSCOPE_MODEL="qwen-plus"
$env:AGENTFORGE_MODEL_PROVIDER="dashscope"
$env:AGENTFORGE_AGENT_ENABLED="true"
mvn -pl agentforge-app -am spring-boot:run
```
